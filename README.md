
# Shop Management System

A desktop-based Shop Management System developed using Java and AWT. This application helps manage products, inventory, customers, and billing operations through a simple graphical user interface.

## Features

- **Dashboard:** Displays total products, total bills, and low-stock items.
- **Add Products:** Add new products with details such as ID, name, price, quantity, category, manufacturing date, and expiry date.
- **View Products:** Display all available products.
- **Search Products:** Search for products using their ID.
- **Update Products:** Update product price and quantity.
- **Remove Products:** Remove products from inventory.
- **Customer Management:** Store customer details and maintain purchase history.
- **Billing System:** Create bills, add products to the cart, calculate the total amount, and generate invoices.
- **Stock Management:** Automatically updates product quantities after successful purchases.
- **File Handling:** Stores and retrieves product and billing data using text files.
- **Exception Handling:** Handles invalid inputs and application errors.

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Shop-Management-System.git
   ```

2. Open the project in an IDE such as Eclipse, IntelliJ IDEA, or VS Code.

3. Make sure Java JDK is installed.

4. Compile the Java files.

5. Run the `ShopGUI.java` file to launch the application.
